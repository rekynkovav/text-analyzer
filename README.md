# Text Analyzer - Многопоточный анализатор частоты слов

## Обзор

Консольное приложение на Spring Boot для анализа текстовых файлов в директории, 
подсчета частоты слов и вывода наиболее часто встречающихся слов. 
Поддерживает однопоточный и многопоточный режимы обработки для сравнения производительности.

## Сборка и запуск

```bash
mvn clean package
```
